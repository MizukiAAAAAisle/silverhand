System Message UI — 优化方案 mockup

paper-ink 主题配色。每节左列是当前渲染、右列是提案渲染。Mock 数据，仅样式参考。

共 11 个当前在用的 subtype，本轮重点优化 P0/P1/P2 共 8 个；mention_cc / thread_summary 现状卡片保留；legacy join / session_context / child_summary / 未知 subtype 走 generic narration fallback。

P0task_create / task_claim / task_unclaim / task_status

DB 1646 条，占系统消息绝大多数。从居中斜体 narration 升级为 task event row——每条独立出现在消息流里它本来发生的位置（同一 task 的事件之间往往隔了很多对话，不连线，靠 #task:N chip 视觉标识 + hover popover 聚合完整历史）。

现状 — 居中 italic narration
@shiki开个 task 跟踪一下。14:00
@shiki created task #299 "system message inventory"
@Cindy我接。14:05
@Cindy claimed task #299
task #299 → in_progress (by @Cindy)
@Cindy梳理完了，发出来。14:38
task #299 → in_review (by @Cindy)
@shiki看了，OK。14:50
task #299 → done (by @shiki)
提案 — task event row（穿插在对话里）
@shiki开个 task 跟踪一下。14:00
@shiki created #task:299system message inventory 14:02
@Cindy我接。14:05
@Cindy claimed #task:299 14:05
#task:299 → in progress by @Cindy 14:05
@Cindy梳理完了，发出来。14:38
#task:299 → in review by @Cindy 14:38
@shiki看了，OK。14:50
#task:299 → done by @shiki 14:50
@Alice unclaimed #task:260 12:15

关于"timeline"语义的澄清：每条 task event 出现在它真实发生的位置，中间隔多少对话都不动；不画连线、不强行聚合。同一 task 的完整历史走 #task:N chip 的 hover popover（已在 PR-4 落地基础设施）或 task drawer，不在 chat 流里串。

P0session_cleared

现状是 toast 风（error bg + border + Eraser 图标，语义偏"危险/删除"）。改成消息流里的轻量 inline audit 行；图标换成"上下文重置"语义的 RotateCcw，不再用错误色。

现状 — toast-like + Eraser
@Alice好的，我先看一下。14:55
user cleared @Alice's CLI session context (prev session: fbe21c8a). Next start will use a fresh session; pending deliveries remain queued.
@shikiOK。14:56
提案 — inline audit row + RotateCcw
@Alice好的，我先看一下。14:55
user reset @Alice 's session context · prev fbe21c8a · was running 14:55
@shikiOK。14:56

icon 候选（lucide）：RotateCcw（首选，逆时针重置箭头）/ History（时钟+逆时针，偏"回看"语义）/ FileClock（偏"会话归档"）。提案选 RotateCcw——它和 "session reset" 的语义最对位，不带删除/错误色彩。

P1schedule_fire

actionable wake，metadata 含 spec_kind / planned vs actual / missed_count / next_fire_at。改成消息流里的扁平 banner（去圆角、左侧 warning 色 accent 线，不再"卡片化"），与现状 narration 拉开层级又不像 toast。

现状 — 居中 italic narration
Scheduled wake (cron */5 9-18 * * 1-5) fired. Reminder: review #task:294 status, ping @shiki if still in_review.
提案 — 扁平 banner（无圆角）
Scheduled wake cron · */5 9-18 * * 1-5
fired just now planned 2s late missed 0 next in 5m
Reminder: review #task:294 status, ping @shiki if still in_review.
Scheduled wake interval · 60s
fired just now planned 4m ago missed 4 next in 60s
Poll deploy status; alert if still pending after 5 cycles.

P1channel_context · child_context · thread_anchor

三种"上下文 / 引用来源"消息当前是"折叠 / 折叠 / 折叠"但视觉无差，用户分不清来源。统一成 context-card 系列：左侧 accent 线区分 kind（Quoted = ink、Inherited = green、Spawned-from = amber）+ inline header tag + source chip，正文低对比；不再用浅底色 header 条（与 chat 背景色太接近）。同时与现有 mention_cc / thread_summary 卡片保持视觉同源。

现状 — 折叠 chevron + 第一行 truncate

▶ Spawn-from #version3 · seed message body for the new sub-channel
