FAVORITES · rail STARRED

#task:1250 · forza6 · 纯视觉 mockup（不接 cursor / 不接后端）

把左 rail 的 STARRED 从「只装 starred workspace」升成全局 Favorites：同一个 starred_at 事实，跨 list_key UNION 出 workspace / DM / channel，铺平一层，每行一个 deep link。

铺平、不分组

  • STARRED 下 workspace 行 / DM 行 / channel 行同列同高，不做二层 workspace 分组（分组=第二棵 tree，扫描慢）。
  • 行高统一 32px 单行：flat 混排里行高不齐会读成「列表在跳」，所以 channel 行不换两行、不缩进。

channel 行怎么自证身份

  • 开头只一个 marker：channel 行 = # glyph，workspace 行 = 方块 monogram icon。形态不同 = 一眼区分频道 / 工作区（没有缩进、没有组标题兜底，全靠它）。
  • 来源 workspace 放在右侧 muted 父 workspace 名，不再在行首塞第二个 ws icon。
  • 这条父 ws 名同时是消歧器：两个 #general 靠它分开（见下方第 4/5 行）。

同名 channel

  • regular workspace 名全局唯一（DB workspaces_regular_name_unique），所以「父 ws 名」副标足够消歧，不需要复杂 UI。
  • 稳定身份永远是 id {kind, wsId, channelId}，绝不靠 name。

显示字段 server-resolved

  • {workspace_id, workspace_name, workspace_icon} 由 Favorites read-model 后端带在每行（沿用 Activity preview_sender 先例），renderer 零本地 join —— 收藏了未加载 ws 的频道也不空窗。

交互

  • 点 workspace 行 = 选中该 workspace；点 channel 行 = deep link /chat/w/<wsId>/c/<channelId>（打开 ws 并进频道）。
  • 行内不放 ★：unstar 走行的右键 / 详情菜单,不占行首也不靠 hover 出图标,保持 32px 行干净。
